# Definition of Done (Лаб 8-аар шинэчилсэн)

Лаб 4-ийн 11 шалгуурыг хадгалж, CI-тэй холбогдох шалгуурыг тодорхой болгов.
**CI** гэж тэмдэглэсэн мөрийг GitHub Actions автоматаар шалгана.

| № | Done гэж үзэх шалгуур | Нотолгоо |
|---|---|---|
| 1 | User Story-ийн хүлээн авах шалгуур бүр хэрэгжсэн. | Story-ийн шалгах хуудас |
| 2 | Код Git репозиторт commit хийгдэж, GitHub-д push хийгдсэн. | Commit hash, PR холбоос |
| 3 | **CI** Build буюу орчны бэлтгэл амжилттай (хамаарал суулгах, `compileall`, `--init`). | Actions-ийн «Build» алхам ✓ |
| 4 | **CI** Холбогдох автомат тест (unit + API) бүгд амжилттай. | `pytest` log, `test-results.xml` |
| 5 | **CI** Python CI workflow Python 3.10 ба 3.12 дээр ногоон дууссан. | Actions-ийн ✓ тэмдэг |
| 6 | CI улаан болсон бол log-ийг уншиж шалтгааныг тодорхойлж, засварын commit хийж, дахин ногоон болгосон. | Улаан ба ногоон run-ийн холбоос |
| 7 | Шинэ функц бүрт тест нэмсэн; тестийг унтрааж, алгасаж CI-г ногоон болгоогүй. | PR-ийн diff |
| 8 | Кодын өөрчлөлтийг багийн өөр гишүүн pull request дээр хянаж approve хийсэн. | PR review |
| 9 | `main` салбарт PR-ээр нэгтгэгдэж, нэгтгэлийн дараах CI мөн ногоон. | `main` дээрх Actions run |
| 10 | Үйлчлүүлэгч бусдын захиалгыг үзэхгүй; зөвхөн эрхтэй ажилтан төлөв өөрчилнө (эрхийн сөрөг тест CI-д багтсан). | TC04, TC12, TC19, TC20 |
| 11 | Нээлттэй critical/high алдаа байхгүй; бусдыг нөлөө, шийдвэртэй нь бүртгэсэн. | Issues жагсаалт |
| 12 | UI нь утас ба компьютерийн дэлгэцэд шалгагдсан. | UI шалгалтын тэмдэглэл |
| 13 | README болон ажиллуулах заавар шинэчлэгдсэн. | README diff |
| 14 | Sprint Goal-ийн урсгалыг зохиомол өгөгдлөөр demo хийх боломжтой. | Demo шалгах хуудас |

Story нь бүх шалгуурыг хангаж байж **Done** болно. CI ногоон байх нь шаардлагатай боловч хангалттай биш: review, UI шалгалт, demo мөн шаардлагатай.
